# Nightmare Ladders

A 3D horror Snakes and Ladders game built with JavaScript and Three.js.

## Run locally

```powershell
npm install
npx http-server -p 4174
```

Open `http://localhost:4174/index.html` in a browser.

## Features

- Two-player setup with names and horse colors
- Configurable snake and ladder counts
- Curved snake and ladder movement
- Horror lighting, sound effects, alerts, and winner celebration
- Interactive 3D camera
